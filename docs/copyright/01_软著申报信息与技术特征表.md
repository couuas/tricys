## 三、 软件用途与技术特点（系统填报文本）

### 1. 软件主要功能（建议填入申报表“主要功能”栏）
> 本软件是一款面向聚变反应堆工程的氚燃料循环全系统多尺度物理仿真与协同分析集成平台，主要功能包括：
> 1. **物理动态闭环仿真**：基于 OpenModelica 物理引擎与 Python 协同仿真架构，实现聚变堆等离子体排灰气回收、同位素分离、储氚供氚及水去氚等多子系统的动态耦合建模与质量守恒仿真。
> 2. **参数扫描与高阶敏感性分析**：支持多维度系统参数自动批量扫参与并发计算，集成 SALib 算法库（Sobol、Morris、FAST）量化关键参数对氚滞留量与系统回收率的敏感性影响。
> 3. **全流程协同仿真（Co-Simulation）**：支持与外部流程模拟工具（如 Aspen Plus）进行双向数据交换，完成复杂工艺单元与动态仿真系统的联合解算。
> 4. **高性能微服务与数据调度**：基于 FastAPI 构建 RESTful API 服务，提供异步任务队列调度、HDF5 海量科学仿真数据快速切片与查询，并通过 WebSocket 实现仿真日志流与监控指标的实时双向推送。
> 5. **3D 数字孪生与交互主控台**：基于 Vue 3 与现代可视化引擎，提供反应堆氚循环工艺流程的 3D 数字孪生展示、可视化拓扑连线配置与实时仿真监控。
> 6. **独立低代码数据大屏**：基于 GoView 架构提供宏观运营级数据大屏，支持多场景多指标动态对比与全局态势感知。
> 7. **AI 增强科研分析与报告生成**：集成大语言模型（LLM）分析能力，自动提取仿真关键特征、折线图及统计指标，一键生成结构化的科研分析报告。

### 2. 技术特征（建议填入申报表“技术特征”栏）
> 1. **多尺度跨学科协同仿真技术**：突破了传统单一物理场工具的局限性，将 Modelica 物理建模、Aspen 复杂化工分离与 Python 数据流深度融合，保障全厂严格的质量守恒。
> 2. **前后端解耦与分布式架构**：前端采用 Vue 3 + Vite 构建轻量高效的响应式主控台，后端采用 FastAPI 异步异步事件循环机制，支持高并发多仿真任务隔离执行。
> 3. **高性能科学数据存储与检索**：利用 HDF5 二进制分块存储技术，高效支持百万级时间步长仿真数据的高速切片与可视化呈现。
> 4. **智能自适应报告合成引擎**：结合 Prompt Engineering 与科学计算指标提取算法，实现了从仿真数值到专业科技报告的智能化自动转化。
