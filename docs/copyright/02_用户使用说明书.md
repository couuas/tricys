## 第 1 章 软件概述与系统架构

### 1.1 系统背景与研发目标
在聚变堆工程研究中，氚燃料循环系统（Tritium Fuel Cycle System）包含等离子体排灰气处理（TEP）、同位素分离系统（ISS）、储氚与供氚系统（SDS/TSS）、水去氚系统（WDS）及尾气去氚系统（VDS）等多个紧密耦合的子系统。各子系统之间存在强非线性、多时间尺度和高安全要求的特征。

**氚燃料循环集成仿真平台软件（TRICYS）** 旨在为研究人员和工程师提供一个全系统、模块化、动态闭环的多物理场集成仿真与数据分析平台，严格遵守全厂范围内的质量守恒原则，支持系统参数寻优、动态工况演化推演以及数字化孪生监控。

### 1.2 总体系统架构
TRICYS 平台采用前后端解耦、微服务化与模块化设计，整体架构由以下四个核心子系统构成：

1. **`tricys`（核心仿真引擎）**：
   基于 Python 与 OpenModelica 深度集成，负责底层的微分代数方程组求解、多参数批量扫参、SALib 敏感性分析、质量守恒审计及基于大模型的报告自动生成。
2. **`tricys_backend`（高性能后端微服务）**：
   基于 FastAPI 框架开发，提供 RESTful 接口管理仿真作业队列、进程生命周期控制、WebSocket 日志流广播以及基于 HDF5 的海量仿真时序数据高效切片提取。
3. **`tricys_visual`（3D 数字孪生前端主控台）**：
   基于 Vue 3、Vite 与现代 Web 渲染引擎开发，提供 3D 反应堆及辅助管网数字孪生可视化、拓扑连线配置与仿真运行状态监控。
4. **`tricys_goview`（独立数据大屏）**：
   基于低代码可视化大屏框架构建，提供宏观运营级全景视图、多方案横向指标对比及多维度趋势展示。

## 第 2 章 运行环境与安装部署

### 2.1 软硬件配置要求

| 项目 | 最低配置 | 推荐配置 |
| :--- | :--- | :--- |
| **处理器 (CPU)** | Intel Core i5 / AMD Ryzen 5 (4核以上) | Intel Core i7/i9 或 AMD Ryzen 7/9 (8核以上) |
| **系统内存 (RAM)** | 8 GB | 16 GB ~ 32 GB |
| **磁盘存储 (Disk)** | 10 GB 可用空间 | 50 GB 以上高速 SSD 存储 |
| **操作系统** | Windows 10 (64位) / Ubuntu 20.04+ | Windows 11 (64位) / Ubuntu 22.04 LTS |
| **显示分辨率** | 1920 × 1080 | 1920 × 1080 及以上 |

### 2.2 基础依赖安装

1. **Python 环境**：推荐 Python 3.10 及以上（最低支持 Python 3.8）。
2. **OpenModelica 物理引擎**：安装 OpenModelica 1.24+，并确保命令行工具 `omc.exe`（Windows）已添加到系统环境变量 `PATH` 中。
3. **Node.js 环境**：前端构建需要 Node.js 18+ 及 npm。
4. **Git 版本控制**：Git 2.40+。

### 2.3 部署向导与启动方式

项目根目录下提供了统一的自动化交互式部署入口脚本 `Makefile.bat`（Windows 环境）。

#### 步骤 1：环境初始化与一键检查
在终端中进入项目根目录，运行部署脚本：
```shell
Makefile.bat
```
向导将自动执行依赖检测（检查 Python、Git、OpenModelica、Node.js 版本），并列出可执行的模式菜单：
* `[1]` 初始化 Python 虚拟环境与核心依赖安装
* `[2]` 启动本地 CLI 仿真环境
* `[3]` 启动 FastAPI 后端服务（默认端口 `8000`）
* `[4]` 启动 Vue 3 前端主控台（默认端口 `5173`）
* `[5]` 启动全栈一体化平台模式

## 第 3 章 核心仿真引擎操作指南

### 3.1 命令行 CLI 主控体系
TRICYS 核心提供了高度模块化的命令行接口，支持通过统一的 `tricys` CLI 或 Python 模块入口进行调度。

常用命令行语法：
```shell
# 查看 CLI 帮助信息
python -m tricys.main --help

# 运行标准仿真配置
python -m tricys.main --config ./example/configs/standard_run.json

# 启动交互式综合示例运行器
python -m tricys.main example
```

### 3.2 动态物理仿真与模型求解
仿真引擎基于 Modelica 物理建模标准定义各子系统（TEP、ISS、SDS、WDS）的微分方程与代数约束。
* **时间步长控制**：支持自适应步长（如 `Dassl`、`Cvode`）与定步长解算器。
* **初始条件设定**：支持通过 JSON 或 YAML 配置文件输入各储罐初始氚滞留量、流体流速、吸附塔温度及回流比等参数。
* **求解结果输出**：求解完成后自动在输出目录生成 `.mat` 或 `.h5` 科学数据结果文件。

### 3.3 多参数扫描与高阶敏感性分析
针对复杂参数调优场景，TRICYS 内置了高级参数空间采样与敏感性评估引擎（基于 `SALib`）：
1. **采样策略**：
   * 支持 Sobol 序列采样（全局敏感性分析）
   * Morris 筛选法（高维参数快速初筛）
   * FAST（傅里叶振幅敏感度检验）
2. **并发计算**：利用 Python 多进程池对不同参数样本点进行并发解算，大幅缩短多工况推演耗时。
3. **结果指标输出**：输出一阶敏感度指数（First-order index）、总阶敏感度指数（Total-order index）及参数交互效应矩阵热力图。

### 3.4 协同仿真（Co-Simulation）数据对接
TRICYS 支持与外部成熟工艺模拟软件（如 Aspen Plus）进行数据耦合：
* **接口协议**：通过 COM/ActiveX 或共享内存接口在各宏时间步（Macro-step）进行状态变量交换。
* **收敛性控制**：内置 Gauss-Seidel 与 Jacobi 迭代松弛算法，保障强耦合工况下的数值稳定性。

### 3.5 氚全厂库存与质量守恒审计
仿真过程中，`tricys.auditor` 模块会实时追踪全厂各节点的质量流：
$$\sum \dot{m}_{in} - \sum \dot{m}_{out} - \frac{d M_{inventory}}{dt} - R_{decay} = \epsilon$$
若质量守恒误差 $\epsilon$ 超过预设容差阈值，系统将触发警报并生成审计分析记录。

## 第 4 章 后端服务与数据管理（tricys_backend）

### 4.1 RESTful API 接口体系与 Swagger 调试
`tricys_backend` 基于 FastAPI 架构构建，服务启动后可通过浏览器访问交互式 API 调试文档：
* **Swagger UI**：`http://localhost:8000/docs`
* **Redoc**：`http://localhost:8000/redoc`

核心 API 分组：
* `/api/v1/projects`：仿真项目创建、配置读取与参数持久化。
* `/api/v1/tasks`：仿真任务提交、启停控制、进度查询与状态转换。
* `/api/v1/data`：HDF5 科学数据切片查询接口。
* `/api/v1/llm`：智能报告生成与提示词交互。

### 4.2 异步任务队列与状态机
后端内置了基于 SQLite + SQLModel 的任务管理引擎：
* 任务生命周期管理：`PENDING`（排队中） $\to$ `RUNNING`（运行中） $\to$ `COMPLETED`（已完成） / `FAILED`（异常失败）。
* **进程崩溃自动恢复**：后端启动时会自动检测孤儿进程，自动识别非正常终止的任务并执行状态安全复位。

### 4.3 WebSocket 实时日志流推送
通过 `/ws/logs/{task_id}` 建立全双工 WebSocket 长连接：
* 后端实时捕获求解器标准输出流并分片推送至前端。
* 前端控制台实现无刷新的实时高亮日志滚动与进度百分比刷新。

### 4.4 HDF5 科学数据存储与切片服务
为满足高频时序数据的高效读写，系统采用 HDF5 分块存储：
* 支持对千万级步长的仿真变量按指定时间区间、采样步长进行高效内存映射切片。
* 前端图表支持平滑降采样渲染，避免大数据量导致的浏览器卡顿。

## 第 5 章 前端主控台与 3D 数字孪生（tricys_visual）

### 5.1 主控台界面布局
`tricys_visual` 前端界面分为四大主要区域：
1. **顶部导航栏**：显示当前项目名称、仿真状态指示灯、快捷操作按钮与全屏切换。
2. **左侧拓扑与模型配置面板**：树状展示 TEP、ISS、SDS、WDS 等子系统组件，支持属性点击编辑。
3. **中央主视图（3D 孪生/拓扑流向图）**：支持在三维数字孪生场景与二维流程拓扑图之间无缝切换。
4. **底部/右侧监控面板**：实时绘制关键变量时序曲线、质量平衡差值与系统实时日志输出。

### 5.2 拓扑配置与参数编辑器
用户可在可视化画布中拖拽调节子系统管道连接关系，并修改各关键设备的工艺参数（如压力、温度、分离因子、回流比等），修改后一键保存并自动同步至后端配置。

### 5.3 3D 数字孪生工艺流程交互
* 采用 WebGL/Three.js 技术构建反应堆厂房与氚循环管网的三维模型。
* 支持鼠标滚轮缩放、右键平移、左键旋转观察。
* 当子系统运行状态改变时，三维管线流体粒子特效与设备发光颜色动态同步变更。

## 第 6 章 独立数据大屏（tricys_goview）

### 6.1 全局宏观态势感知大屏
`tricys_goview` 面向监控指挥中心和大屏展示场景设计：
* **全景看板**：集中展示反应堆总氚库存、全厂日处理能力、回收率（Recovery Fraction）及排放监测指标。
* **预警中心**：当局部管道浓度或储罐滞留量超过阈值时，大屏以高亮警报弹窗提示。

### 6.2 多工况动态对比与分析视图
* 支持同时加载多组历史仿真试验或不同参数扫描方案的数据。
* 提供雷达图、箱线图、热力图等多维度综合对比视图，便于工程师快速筛选最优工艺设计参数。

## 第 7 章 AI 增强分析与智能报告生成

### 7.1 LLM 分析配置
TRICYS 平台支持接入主流大语言模型（OpenAI API / 本地开源 LLM 服务）：
1. 在系统设置中配置 API Key、Base URL 及模型名称（如 `gpt-4o`、`deepseek-chat` 或本地部署模型）。
2. 配置科学分析提示词模板（Prompt Templates），设定报告的专业严谨性风格。

### 7.2 自动生成科技分析报告
仿真完成后，点击 **“生成分析报告”** 按钮：
* 系统自动提取仿真峰值、稳态达标时间、各节点质量守恒误差等关键指标。
* 结合自动绘制的 SVG/PNG 趋势曲线图，调用大模型生成包含“背景”、“方法”、“结果讨论”、“优化建议”的学术规范级 Markdown 分析报告，并支持一键导出为 PDF 格式。

## 第 8 章 常见问题与维护排查

| 现象 / 异常 | 可能原因 | 解决方法 |
| :--- | :--- | :--- |
| **启动时提示找不到 omc 命令** | OpenModelica 环境变量未配置 | 将 OpenModelica 安装路径下的 `bin` 目录（含 `omc.exe`）加入系统 `PATH` 环境变量并重启终端。 |
| **前端图表无法接收实时日志** | WebSocket 连接受防火墙拦截或端口被占用 | 确认后端 `8000` 端口正常监听，检查浏览器控制台 WS 连接地址与代理配置。 |
| **大参数量扫参内存占用过高** | 并发进程数设置过多 | 在配置文件中降低并发 Worker 数量（推荐设置为物理 CPU 核心数 - 2）。 |
| **HDF5 数据读取报权限冲突** | 仿真进程尚未释放文件写锁 | 确认当前任务状态已进入 `COMPLETED`，或在后端配置中开启文件共享只读模式。 |
